# 訓練圖庫前綴辨識修正 — 1.1.0.15

2026-11-04，使用者無法匯入 E:/0_軟體開發區/4.測試實驗區/TrainingImage。

原因：
- 原式只接受 CCD1～10，不接受 CCD01。
- GUI 必須選產品 CCD 子資料夾，根目錄不推斷唯一前綴。
- 原式把 CCD 相機號當站號，忽略同 CCD 目錄中的其他站，例如 CCD01 內第 5 站。

已修改：
- TrainingImageDiscovery 支援補零與舊式命名、唯一前綴推斷、從 Original／Origional 內真正站號取路徑；仍依 stationCount 篩選，不讀 X／Y。
- 多產品要求選產品子目錄，多版本保留候選供 GUI 選擇，避免自動混用。
- RecipeManager.ImportTrainingImageRecipe 共用相同辨識，仍清空 ALL；無圖片分類保留 null，同站多版本拒絕自動匯入並指引逐站選取。
- 修正資料夾選擇提示與版本／README，新增可重現的辨識檢查。

驗證：
- 真的圖庫僅讀取目錄與圖片數量：1站 244 OK／259 NG；2站 165／541；3站 93／563；4站 37／331；5站（CCD01）56／39；6站 88／455。
- 通過 root／巢狀 OK・NG、補零、舊 CCD1・CCD10、同相機多站、缺分類、多產品歧義、多版本不合併、站數上限、無 CCD1 也能推斷前綴與 regex 特殊字元測試。
- net472 x64 Slim 建置成功，git diff --check 通過；未將真實圖庫套用到正式配方，以免改掉使用者設定。

部署：使用者再次授權後續直接關閉→更新→重啟。部署前舊程式已結束，主程式與 PDB 已更新並核對 SHA256，已重新開啟 1.1.0.15，主視窗標題與版本正確且 Responding=true。未自動套用訓練圖庫到正式配方。
