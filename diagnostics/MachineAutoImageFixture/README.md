# 機台自動存圖測試圖庫

供 LumasharpChecker 未來的年／月／批號或日期／OK／NG／站別掃描邏輯使用。

執行 `生成測試圖庫.ps1`，預設輸出至 `_output/存圖/2026/10/`，四種批號或日期資料夾：

- `LOT-A1001`：純批號
- `20261025`：日期
- `2026-10-28_LOT-B2002`：日期混合批號
- `31`：日

每一組均有 `OK/1～8`、`NG/1～8`，每站各一張 320×240 的有效 PNG，總共 64 張。所有圖片都標記 TEST ONLY，**不是**正式點檢標準件或產線圖片。

若電腦確實有 E:，之後可手動指定輸出路徑：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\生成測試圖庫.ps1" -OutputRoot "E:\存圖"
```

這支腳本不刪除檔案，也不覆寫任何同名 PNG。請先確認目標位置是專用測試資料夾，勿與正式機台存圖混在一起。
