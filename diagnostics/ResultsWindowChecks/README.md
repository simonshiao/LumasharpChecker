# 結果視窗元件驗證

以實際發布的 WPF 視窗組件建立記憶體測試資料，不顯示測試視窗、不執行正式檢測或寫入配方。需 net472 x64、WPF，使用 `-p:LumaAssemblyPath=<受測EXE>` 編譯，執行參數依序為受測 EXE、App 依賴 DLL 目錄、選填的圖片路徑文字清單。請以 --artifacts-path 指向專用暫存目錄。

涵蓋原有 NG-only 模式改為全縮圖預設、亮度上下限、OK／NG／Retest 篩選與數量、縮圖開關／緊湊列、光源略過無適用上下限。圖片清單若提供，另測第一次 6 張（或清單長度）縮圖解碼與全 OK 在 NG-only 時沒有解碼；不是端到端視窗渲染或檢測效能測試。
